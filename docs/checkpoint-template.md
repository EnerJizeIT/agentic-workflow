# Чекпойнт этапа

Шаблон ручного отчёта на стыке этапов: что доказано, чем заплатили, что
осталось и готов ли следующий этап. RUN-REPORT ссылается на этот файл, но
не заполняет его — разделы пишет супервизор по фактам этапа.

## Что доказано (строки матрицы)

Строки приёмки этапа и их статус: `строка -> доказательство (тест, коммит,
замер)`. Строка без доказательства — не доказана, даже если работа сделана.

- [ ] <строка матрицы> — <где доказано: файл::тест / commit / лог>

## Цена

Сколько стоил этап в понятных единицах: витки юнитов, прогоны сьюта,
токены/время, ручные подъёмы храповика. Называй источник каждой цифры.

- <метрика>: <значение> — <источник>

## Остатки

Что сознательно перенесено и куда (файл бэклога, следующий этап). Перенос
без адреса — потерянная находка.

- <остаток> -> <адрес переноса>

## Готовность следующего этапа

Входы следующего этапа: что должно быть в дереве, какие решения приняты,
какие блокеры сняты. «Готово» без списка входов — не готовность.

- <вход / решение / блокер> — <состояние>

# 09 — Инструменты доказательства

**Роль:** инженер тестовой инфраструктуры. **Проверка:** A-19, `prove_red`, `verify_pack`, mutation smoke.

**A-19:** `awf/prove_red.py` удерживает путь теста внутри временного worktree; адресные сценарии `..`, абсолютного пути и symlink на внешний файл, включая уже существовавший в baseline symlink, прошли (`test_audit25_a19_prove_red_paths.py`). Проверка красного baseline и классификация `broken-runner` представлены тестами шестой волны. `verify_pack` собирает гейты, diff, команды контракта и `prove_red` в отдельный отчёт.

Текущий контракт допускает TODO без блока `verify/prove_red`, поэтому `verify_pack` пишет `skipped` для отсутствующих частей. Это честный статус, но не механическая гарантия доказательства каждого исправления. `awf_verify_pack` с полным suite может превысить MCP транспортный тайм-аут; этот случай открыт в `BACKLOG.md`.

**Вывод:** исходная граница A-19 закрыта; качество доказательства зависит от содержания контракта юнита и длительности вызова MCP.

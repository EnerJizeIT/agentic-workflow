# 10 — Мёртвый код и достижимость

**Роль:** инженер сопровождения. **Проверка:** кандидаты D-01/D-02/D-03 исходного аудита и остаточное дублирование.

- **D-01:** `read_include_list` больше не мёртвый: `awf/api/run.py:751` использует общий парсер `.include`; `test_audit25_d01_include_parser.py` проверяет прямой вызов и путь `run_next`.
- **D-02:** `working_tree_clean` удалён из `awf/git_utils.py`.
- **D-03:** `load_reference_costs` удалён из `awf/metrics.py`. Для обоих удалений есть проверка отсутствия символов в `test_audit25_w6_hygiene.py`.

Статический поиск других потенциально неиспользуемых публичных функций не даёт безопасного списка на удаление: CLI, MCP и сторонние импорты используют динамические входы. В этом повторном проходе новых кандидатов с доказанной недостижимостью не установлено. Основной долг сейчас не мёртвые определения, а пересекающиеся фасады состояния и tools; см. [11](11-refactoring.md) и [15](15-tools.md).

**Вывод:** три прежних кандидата обработаны; новых безопасных удалений без анализа внешнего контракта нет.

# 05 — Локальные HTTP границы

**Роль:** инженер HTTP. **Проверка:** A-03/A-07 на core checkpoint и сервере форм.

**A-03:** решение checkpoint привязано к пути `/checkpoint` и одноразовому токену; проверка и списание токена происходят под одним lock (`awf/plan_checkpoint.py`). Тесты отказа без токена, с чужим/не-ASCII токеном, повторного POST и неверного пути прошли (`test_audit25_a03_checkpoint_token.py`). **A-07:** оба обработчика проверяют `Content-Length` до чтения, ограничивают размер и время чтения; тесты неполного и большого тела, неверной длины и лимита обработчиков прошли (`test_audit25_a07_http_body.py`, `test_audit25_a07_plugin_body.py`).

Вывод ограничен локальными серверами и проверенными путями POST. Нагрузочный сетевой тест на длительную эксплуатацию не проводился. Код находится в `awf/plan_checkpoint.py` и `agent_workflow_ui/src/agent_workflow_ui/http_endpoint.py`.

**Вывод:** исходные A-03/A-07 подтверждены.

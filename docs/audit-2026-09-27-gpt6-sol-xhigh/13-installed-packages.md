# 13 — Установленные пакеты

**Роль:** инженер упаковки. **Проверка:** оба wheel после установки вне дерева исходников.

`bash scripts/wheel-smoke.sh` завершился с кодом 0 на Python 3.12. Собраны `awf-1.4.0` и `agent_workflow_ui-1.4.0`, установлены в отдельный venv; проверены `awf --help`, импорт `awf.api` и плагина из `site-packages`, наличие `SKILL.md`, регистрация 47 MCP tools, рендер project-setup и запуск entry point с изолированным XDG. Рабочее дерево не входило в `sys.path` smoke-сценария. В CI этот же скрипт настроен для Python 3.10 и 3.12, но удалённый CI этого коммита здесь не проверялся.

Изменения packaging после `v1.4.0` до данного аудита не обнаружены. Локальная сборка создала игнорируемые `dist/`, `build/` и metadata каталоги; они удалены после фиксации результата, поскольку отчёту нужны результаты, а не временные бинарные файлы.

**Вывод:** локальный установленный пакет работоспособен в проверенном объёме; матрица Python 3.10 подтверждена конфигурацией CI, не локальным исполнением.

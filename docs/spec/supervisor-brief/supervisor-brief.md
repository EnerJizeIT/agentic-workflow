# Требования: единая инструкция супервизора через `awf_brief`

Статус: REVIEW
Ревизия: req-11
Входы: supervisor-brief.context.md@ctx-2, TODO-0326 (витки 1–5), TODO-0327, TODO-0329,
supervisor-brief.requirements-review.md@reqrev-10, supervisor-brief.readiness.md@rd-4
База кода: 40bb6cc; артефакт бейзлайна 85ec91a отстал, факты пересняты.
Пути: `agent_workflow_ui/src/agent_workflow_ui/tools/awf.py` («MCP-тулы»), `awf/brief.py`,

Термины: **бриф** — ответ `awf_brief`; **карточка** — его текст.

## Цель и scope

Супервизор в непонятный момент зовёт `awf_brief` и понимает, что происходит, что
делать и в каком порядке. Сейчас вход делят четыре тула (CTX1). Решение
владельца 02.11: `awf_brief` — единственный вход, `awf_current_step` и
`awf_load_supervisor_context` **удаляются** из MCP, без обёрток `deprecated`.

В итерации R1–R11. Вне: новые MCP-тулы, движок, `awf/verify_pack.py`,
`DONE.json`/handoff, гигиена очереди, CTX9 и CTX10 — уходят с тулом. Пайплайн —
`.agentic/pipelines/spec-supervisor-brief.yaml` (RR16). Коммит-гейт — вне по
поведению; в scope поле `reason` в `COMMIT-AUDIT-<id>.json` (A8).

Очередь (RR21, RR27): TODO-0325 (A24) снят, `log_tail` — в R9.

## Текущее поведение и ограничения

Совет владеет `next_action_from_status` (`awf/brief.py:703`), второй тул
подменяет его словарём фаз (2559–2574) — два совета (CTX2). Правило ожидания
спорит с собой (3008–3017, CTX3). Карточка — 954 слова при потолке
900 (CTX4); `log_tail` — прошлый юнит; вердикты `GATES` и коммит-гейта не
читаются; карта статическая (CTX5–CTX7). Промпт фазы (775 слов, 5076 символов)
не влезает: бриф даёт выдержку и «full version: `awf_current_step`» (CTX14).
После снятия имени MCP отвечает `Unknown tool` (CTX12).

Источник: TODO-0326 п.1, виток 4; CTX1.

места: `tools/awf.py:2526` «Replaces 5-6 separate tool calls at session start or

вызовов» по дереву и сгенерированным файлам.

непонятный момент, потеря контекста, смена стадии.

в тесте; после — 54, разница ровно
`{awf_current_step, awf_load_supervisor_context}`; иное — провал. Сценарий: C10.

AC28 — вердикт **текущего прохода**: юнит из state (`todo_id`); в статусе —
`current_todo` (D7), один признак для одиночного `awf start` и забега.

текущего прохода (AC28); до попытки — «коммита ещё не было»; лог не считается.

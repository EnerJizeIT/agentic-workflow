# Исторический пакет: переход на opencode 2.x

Этот пакет (`opencode2.md` и его спутники) описывает ПЕРЕХОД awf 2.3.0 на
opencode 2.x: требования R1–R8, архитектуру K1–K10 и план IMP1–IMP6 того
перехода. Переход выполнен, awf 3 работает только на opencode 2.x, и
актуальное описание живёт в `docs/design/opencode-v2-migration.md`.

Пакет сохранён как история решений: он объясняет, почему появились
preflight, единый argv-помощник и kill группы процессов. Для работы и для
приёмки новых изменений он не используется; тексты документов не
поддерживаются.

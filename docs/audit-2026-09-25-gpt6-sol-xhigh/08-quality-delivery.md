# Слой 8 — тесты, CI, упаковка и документация

**Роль:** инженер качества и сопровождения. Просмотрены организация тестов, quality gates, workflow CI, пакетные манифесты, реестр MCP tools и основные документы.

## Оценка покрытия сценариев

В репозитории 119 Python-файлов тестов и около 2453 определений тестовых функций/методов. Есть unit, integration, e2e и negative сценарии. `scripts/run-all.sh` объединяет контрактные проверки, счётчики долга, инструкции, полный pytest и Ruff; CI вызывает этот скрипт и отдельно проверяет содержимое wheel. Это сильная основа для регрессий. Статическая команда `ruff check awf agent_workflow_ui/src --output-format concise` при аудите завершилась без замечаний. Позже адресно запущены 122 теста по состоянию/архиву/очереди; они прошли. Полный test suite не запускался.

У найденных дефектов остаются конкретные непокрытые ветви: pre-staged чужой index; две попытки запуска на одном проекте; ложный `False` commit gate на execute стадии; коллизии `restore`/`archive`; повторный `init` с живым runtime; отказ применения формы после статуса `submitted`; HTML строка в имени/содержимом скилла; пятизначный TODO в метриках. Это список адресных сценариев для исправлений, не утверждение об отсутствии иных тестов.

## A-18 · P3 · Wheel плагина собирается, но не проверяется как установленный пакет

CI [собирает оба wheel и проверяет несколько файлов внутри](../../.github/workflows/ci.yml#L57), затем в чистом venv [устанавливает и запускает только core wheel](../../.github/workflows/ci.yml#L71). Тестовая job устанавливает оба пакета editable, поэтому не проверяет импорт, MCP registration и шаблоны именно из wheel плагина. Ошибка package-data или entry point плагина может пройти CI при корректном core wheel.

**Рекомендация:** добавить smoke установку `agent-workflow-ui` из собранного wheel в чистом venv и проверить импорт сервера, регистрацию tools, рендер стандартного шаблона и запуск entry point с закрытым stdin. Для заявленной поддержки Python 3.10–3.12 рассмотреть матрицу хотя бы для минимальной и максимальной версии. Ручная проверка текущего wheel на всех трёх версиях прошла ([слой 13](13-installed-packages.md)); пробел CI остаётся.

## Ограничение

Без запуска полного suite нельзя утверждать, что он зелёный. Положительный результат Ruff означает отсутствие замечаний только от указанной статической конфигурации; адресные проверки состояний и конкуренции приведены отдельно в [слое 12](12-recovery-reliability.md).

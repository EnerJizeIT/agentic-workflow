# Слой 10 — неиспользуемый код и достижимость

**Роль:** инженер сопровождения кода. Проверены определения функций, классов и модульных констант в продуктивных Python-пакетах и обращения к ним в этих пакетах и 119 тестовых Python-файлах. Дополнительно имена кандидатов искались по всему репозиторию. Это поиск **внутренних ссылок**, а не доказательство отсутствия внешних пользователей публичных модулей.

## Метод и результат

AST-проход учитывал обращения вида `name`, `module.name` и `from module import name`; строковый поиск подтвердил каждый кандидат. Частные функции с нулём внутренних обращений не найдены. Среди функций верхнего уровня нашлись три определения без вызова в репозитории:

| ID | Кандидат | Доказательство | Оценка |
|---|---|---|---|
| D-01 | [`read_include_list`](../../awf/include_untracked.py#L51) | В [`run_next`](../../awf/api/run.py#L642) тот же `.include` файл читается и разбирается вручную; имя функции встречается лишь в определении, описании модуля и `__all__`. | Высокая уверенность, что **внутри проекта** функция не исполняется; внешнее использование неизвестно. |
| D-02 | [`working_tree_clean`](../../awf/git_utils.py#L92) | Обёртка над `status_porcelain`; в коде, тестах, скриптах и документах вызова по имени нет. | Высокая уверенность для внутренних вызовов; `git_utils` можно импортировать извне. |
| D-03 | [`load_reference_costs`](../../awf/metrics.py#L745) | Обёртка последовательно вызывает `load_models_catalog` и `model_costs_from_catalog`. [`collect_metrics`](../../awf/metrics.py#L1534) пользуется этими шагами отдельно из-за fallback на кэш; вызова обёртки нет. | Высокая уверенность для внутренних вызовов; возможны внешние пользователи `awf.metrics`. |

## Рекомендация по каждому кандидату

**D-01:** использовать существующий `read_include_list` в `run_next` и убрать ручной разбор либо удалить helper и исправить документацию/`__all__`. Первый путь сохраняет совместимость и устраняет вторую реализацию формата `.include`.

**D-02:** если `git_utils` не считается публичным API, удалить одношаговую обёртку. Если публичен, зафиксировать функцию в поддерживаемом контракте и покрыть сценарием использования; иначе она создаёт ложное впечатление востребованного API.

**D-03:** проверить обещания совместимости для `awf.metrics`. При отсутствии внешнего контракта удалить обёртку, оставив фактически используемые функции загрузки и fallback; при наличии контракта явно обозначить статус и проверить поведение на недоступном каталоге.

## Граница вывода

Динамические обращения через `getattr`, import hook, конфигурацию и сторонний код статический поиск может пропустить. Поэтому эти три пункта названы кандидатами, а не безопасным списком на удаление. Адресных тестов на удаление кандидатов не выполнялось; исходный код не менялся.

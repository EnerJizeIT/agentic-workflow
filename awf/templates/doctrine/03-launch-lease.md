# Отказ при одновременном запуске — noop с текстом, не исключение

Одновременные вызовы запуска (`awf start`/`awf continue`, MCP
`awf_start`/`awf_run_next`) дают ровно один выполняющийся пайплайн —
для background, foreground и смешанных пар. Окно «живость →
спавн/старт» закрыто lease
(`awf-launch.lease`; stale — по живости процесса, не по возрасту
файла); для foreground окно — весь прогон: его живость появляется в
state только после первой стадии. Остальные получают
`run_mode="noop"` с текстом «another launch is already in progress»
— не исключение, не блокирующее ожидание.

Почему: noop с текстом — форма соседних отказов по состоянию
(«Pipeline already running»): MCP не превращает её в ошибку, текст
указывает на `awf_status`. Исключение значило бы «сбой вызова», а
запуск уже идёт — это нормальное состояние.

# Отказ при одновременном запуске — noop с текстом, не исключение

Одновременные вызовы запуска (`awf start`/`awf continue`, MCP
`awf_start`/`awf_run_next`) дают ровно один спавн: окно
«проверка живости → спавн → запись PID-файла» закрыто lease
(`awf-launch.lease`, O_EXCL с pid владельца; stale — по живости
процесса, не по возрасту файла). Остальные вызовы получают
`run_mode="noop"` с текстом «another launch is already in
progress» — не исключение, не блокирующее ожидание.

Почему: noop с текстом — форма соседних отказов по состоянию
(«Pipeline already running»): MCP-обёртка не превращает её в ошибку,
текст указывает на `awf_status`. Исключение значило бы «сбой
вызова», а запуск уже идёт — это нормальное состояние.
